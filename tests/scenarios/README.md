# Фиксированный приёмочный сценарий

`create_fixed_world()` всегда создаёт сектор `test-sector`, четыре системы,
двенадцать поселений и ресурсы `food`, `ore`, `fuel`, `goods`. Все физические
величины и деньги целочисленны, поэтому товарный и денежный балансы должны
сходиться **точно**.

`test_fixed_world.py` проверяет 100-летний прогон, 1/2/4 worker-потока, LOD
0/1/2, ручную фиксацию LOD 2, календарные переключения и эквивалентность
save/load. Инварианты проверяются после каждого месяца. Эталон точности — 10 лет
LOD 2; допустимые отклонения LOD 0/1: 2% для населения/выпуска/потребления,
запасов, торговли и инфраструктуры, ±2 месяца для кризисов и точное совпадение
типов причинных связей. Текущая фиксированная модель точнее этих бюджетов.

Профиль запускается отдельно, чтобы нестабильная скорость CI не делала
функциональную сборку красной:

```bash
python -m tests.scenarios.profile --years 100
```

Он выдаёт JSON с общим временем, тиками/с, пиковой памятью, размерами save и
истории, ускорением 2/4/8 worker-потоков, временем фаз и задержкой переданного
probe HTML-интерфейса. Скорость — измерение, а не универсальный порог.
